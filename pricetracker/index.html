Story · Price-watch bot

Automate checking prices

I was checking washing machine prices online every day. So I built a bot to do it for me.

How it works

7:00 am

Every morning the bot checks the prices of the washing machines on my list.

Only when it matters

It messages me on Telegram only when one drops $100 below my target price.

The result

It saved me $157, for about $1 in running costs.
